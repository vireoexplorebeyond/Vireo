VIREO V9 — BIG DETAIL BUILD

This is a clean rebuild of the website rather than a patch over V8.

Includes:
- Same minimalist Vireo visual approach and DM Sans font.
- Scottish Highlands homepage background.
- Seven discovery moods.
- Places beyond mountains.
- Near Me starter cities.
- After the Adventure.
- Weekend Escapes.
- Passport + European Trails coming soon.
- Data-driven directories with individual profiles, difficulty and 1–5 view ratings.
- 214 Wainwright records, 282 Munro records, 15 Welsh 3000 records and 129 Peak District records.
- No maps, live GPS, parking or route data yet.

Upload EVERYTHING in this folder to the ROOT of the GitHub repository.
This package contains its own data.js, script.js and styles.css.

The difficulty labels are Vireo's prototype editorial ratings, not official route classifications.
Descriptions are intentionally concise and should be fact-checked/expanded before commercial launch.
