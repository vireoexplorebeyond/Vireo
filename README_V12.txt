VIREO — MASSIVE IMMERSIVE BUILD

This build keeps the dark, minimal Vireo identity and expands the prototype substantially.

WHAT'S INCLUDED
- 640 summit/hill records: 214 Wainwrights, 282 Munros, 15 Welsh 3000s, 129 Peak District.
- Every summit has a description plus extra Vireo fields for why to visit, field notes, planning notes, collection, area, difficulty and view rating.
- Search and sorting on all four summit directories.
- Difficulty filters: Easy / Moderate / Hard.
- Save buttons using local browser storage.
- Log Adventure buttons using local browser storage.
- Clickable profile drawer with Overview / Field Notes / Plan Ahead tabs.
- Share profile link button.
- Vireo Passport page with local collection and progress counters.
- Places Worth Going page with destination imagery, descriptions and coming-soon planning sections.
- Homepage discovery choices and Near You city selectors.
- Weekend Escape cards.
- Robust image fallback so a failed remote image never leaves a broken-image icon.
- Dark Vireo identity retained; no cream redesign.

UPLOAD
1. Unzip this folder.
2. Upload the contents to the root of the existing GitHub Pages repository.
3. Commit changes.
4. Refresh the live site with a hard refresh if the old CSS/JS is cached.

IMPORTANT
The current prototype intentionally labels route, parking, exact location, weather and live conditions as coming soon. Do not treat the generic profile copy as route instructions.
